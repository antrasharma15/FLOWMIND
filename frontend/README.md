# FlowMind Frontend 🎨

The user interface for FlowMind, built with a focus on cinematic aesthetics and fluid performance.

## 🚀 Features
- **Glassmorphic Design**: Deep translucency and vibrant gradients.
- **Micro-interactions**: Smooth transitions using Framer Motion.
- **Dynamic Dashboards**: Responsive layouts for task analytics.
- **AI Integration**: Interactive AI chat and suggestion panels.

## 🛠️ Tech Stack
- **React 18**
- **Vite** (Build Tool)
- **Tailwind CSS** (Styling)
- **Framer Motion** (Animations)
- **Lucide React** (Icons)

## 🏃 Getting Started
1. `npm install`
2. `npm run dev`

## 📁 Structure
- `src/components`: UI building blocks.
- `src/pages`: Main application views.
- `src/demo`: Components for the simulated walkthrough experience.
- `src/context`: State management.
